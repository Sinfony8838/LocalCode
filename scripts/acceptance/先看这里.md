# 帮我试一下 LocalCode：先做这几步就行

这是我做的一个 Windows 编程助手测试版，想请你帮忙看看，在另一台电脑上能不能正常打开。你不用会写代码，先按下面步骤试一下就可以。

## 第一步：把文件解压出来

我会给你三个压缩包：

- 名字带 `windows-x64-candidate` 的：这是可以直接打开的软件，**先用这个**。
- 名字带 `acceptance` 的：这是检查工具和操作说明。
- 名字带 `source-candidate` 的：这是源码，先不用打开。

1. 在“文档”里新建一个文件夹，可以叫“LocalCode 中文 测试”。
2. 右键软件压缩包，选“全部提取”，完整解压进去。检查工具压缩包也解压到另一个新文件夹。
3. 不要在压缩软件里面直接双击 EXE。暂时不用装 Node、Python、Git 或 Ollama，也不用改环境变量。

## 第二步：做一次电脑检查

1. 打开刚才解压的检查工具文件夹，双击 `Check-Environment.cmd`。
2. 等它运行完，文件夹里会出现 `results`，里面有一个 `environment-...json` 文件，留着发我。
3. 如果显示 `False`，不代表软件坏了，只说明这台电脑不完全符合“干净电脑测试”的条件。把结果发我就行，不要为了测试卸载软件、改账号或修改系统设置。

如果红字提示“在此系统上禁止运行脚本”，说明拿到的是旧版检查启动器。请向我拿修正版 `Check-Environment.cmd`，覆盖检查工具文件夹里的同名文件，再双击一次；不用重下软件包。修正版只为这一次检查进程指定执行方式，不修改电脑的长期执行策略。如果仍被单位／学校的组织策略阻止，保留截图发我，不要修改策略。

不用选择“以管理员身份运行”。如果打不开，或者 Windows／安全软件出现提示，截图发我，先停在这里；不需要关闭防护。

## 第三步：打开软件

1. 打开解压后的软件文件夹，找到最外层的 `Start.cmd`，双击。
2. 等待出现 LocalCode 主窗口。
3. 打开“设置”，看看页面能否正常显示、按钮能否点击。检查完关闭设置，再关闭软件，重新打开一次。

看到“Ollama 未连接”或“模型尚未安装”可以先不用处理。第一轮只是看软件能否启动、设置能否打开，不要求它现在就回答问题。

**这一轮不用输入 API Key，不用测试自己的私人项目，也不用下载模型。**

## 第四步：把结果发我

直接照下面回复就行：

> 电脑系统：Windows 10／11／不清楚
>
> 软件能否打开：能／不能
>
> 设置能否打开：能／不能
>
> 关闭后重新打开：正常／有问题
>
> 遇到的提示或卡住的地方：……

另外发我：

- 一张软件打开后的截图；打不开就发报错截图。
- 检查工具生成的 `environment-...json` 文件。

不要把整个软件的数据文件夹、密钥、私人项目或聊天记录发过来。如果截图里有个人信息，先遮住。

## 后面的测试，等我确认这一轮后再做

后续还要测试源码安装、本地模型下载、修改测试文件，以及重启电脑后能否继续使用。模型会下载好几 GB，需要足够空间和时间；先不用自己尝试配置。确认电脑条件后，我再告诉你做哪一步，详细步骤也放在 `README.zh-CN.md` 里。
