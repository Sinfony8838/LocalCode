This is logpulse, a log-ops CLI. docs/CI-GUIDE.md is the external contract, including the defect you must fix: when the target file exists and --force is absent, the `report` sub-command enters an overwrite-confirm branch whose current implementation waits forever for a stdin 'data' event in non-interactive contexts (EOF never produces 'data'), hanging CI; the interactive path spawns scripts/asker.cjs with no watchdog, so a slow helper stalls the pipeline. Fix per the contract in CI-GUIDE.md: in non-interactive contexts do not read stdin and do not spawn the helper — fail immediately with exit code 2 and a stderr message containing 'non-interactive'; on the interactive path wait for asker behind a 3-second watchdog and treat a timeout as declined (exit code 3). scripts/asker.cjs is a protected child-process contract (it waits for one stdin line or prints 'n' after at most 10 seconds) — do not modify it. The stats and rotate sub-commands must keep their behaviour; do not modify README.md, package.json, docs/ or anything under test/ except test/report.test.mjs. Run `npm test` afterwards to confirm every test passes.
