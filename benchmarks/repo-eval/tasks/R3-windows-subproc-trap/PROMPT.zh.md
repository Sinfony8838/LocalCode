这是 logpulse，一个日志运维 CLI。docs/CI-GUIDE.md 是对外契约，其中标注了本次必须修复的缺陷：`report` 子命令在目标文件已存在且未加 --force 时进入覆盖确认分支，而当前实现在非交互环境（stdin 不是 TTY）会永远等待 stdin 的 data 事件（EOF 时 data 永远不来），CI 由此挂死；交互路径派生的 scripts/asker.cjs 也没有任何看门狗，慢助手会拖死流水线。请按 CI-GUIDE.md 的契约修复：非交互环境下不读 stdin、不派生助手、立即以退出码 2 失败并向 stderr 输出包含 non-interactive 的信息；交互路径用 3 秒看门狗等待 asker，超时按拒绝处理（退出码 3）。scripts/asker.cjs 是受保护的子进程契约（等待一行 stdin 或最多 10 秒后输出 n），不要修改它。stats 与 rotate 子命令行为不得改变；README.md、package.json、docs/ 与 test/ 下文件不要修改（test/report.test.mjs 除外）。完成后运行 `npm test` 确认全部测试通过。
