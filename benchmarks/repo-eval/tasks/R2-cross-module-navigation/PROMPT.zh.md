这是 orderbus，一个事件驱动的订单流水线。docs/INCIDENT.md 是一线报来的线上工单：同一事件循环 tick 内并发提交的状态迁移会互相踩踏（重复应用、漏应用、版本号不动）。请阅读工单并按其中规定的语义修复：store/orders.mjs 的 apply 必须支持期望版本校验并递增 version；core/machine.mjs 的 transition 必须按订单串行化同 tick 迁移并把存储的版本冲突映射为 {ok:false, reason:'stale'}；plugins/auto-ship.mjs 必须改为调用并等待 machine.transition 的结果，只有 ok 时才广播 order:shipped。不要修改 README.md、package.json、docs/、test/ 以及 reporting/、compat/ 下的任何文件（它们是无关模块，改动会导致回归检查失败）。完成后运行 `npm test` 确认全部测试通过。工单语义是验收标准的唯一来源，评分还会运行未公开的边界测试。
