# LocalCode 动画图集协议

最终文件为非交错、8 位 RGBA PNG，尺寸 **1536×2288**，8 列×11 行，每格 **192×208**。透明画布，无网格线、文字、标签、背景或格间距；每一帧人物整体落在自己的格内。头部、光环、尾巴等不能越过格子，人物脚底和视觉中心在各帧中保持一致。

| 行（从 0 开始） | 动作 | 使用帧数 | 播放速度 |
| --- | --- | --- | --- |
| 0 | 待机、呼吸 | 6 | 4 fps |
| 1 | 向右移动 | 8 | 8 fps |
| 2 | 向左移动 | 8 | 8 fps |
| 3 | 招手 | 4 | 5 fps |
| 4 | 跳跃 | 5 | 6 fps |
| 5 | 失败、失落 | 8 | 4 fps |
| 6 | 等待用户确认 | 6 | 3 fps |
| 7 | 工作、思考 | 6 | 4 fps |
| 8 | 完成、庆祝 | 6 | 4 fps |
| 9 | 目光方向 0–7 | 8 | 静态方向 |
| 10 | 目光方向 8–15 | 8 | 静态方向 |

前九行的有效帧从最左格开始，其余格子透明。后两行是同一角色的十六张朝向/目光姿态，方向角从屏幕正上方起，每次顺时针增加 22.5°（0 向上、4 向右、8 向下、12 向左）；不得用这两行代替前九行动画。

可导入清单只包含以下字段，图集是清单同目录的相对文件名：

```json
{
  "name": "星云猫",
  "description": "戴小围巾的银白色猫咪，思考时尾巴轻摆。",
  "atlas": "pet.png"
}
```

名字 1–80 个字符，说明最多 500 个字符。不要把 API 密钥、绝对路径或图片 URL 写入清单。

## 生图提示词要点

先具体描述角色轮廓、服装、配色、材质和风格，再要求：one consistent character, transparent RGBA sprite atlas, exactly 8 equal columns and 11 equal rows, no borders, no labels, no text, no gutters; fixed framing and baseline; continuous motion within each animation row。附上上表对应的动作和有效帧数，不要求供应商不支持的输出尺寸。

图片 API 可能无法严格遵循网格。`pack` 能将已有正确网格整体缩放至标准尺寸、检查必需格子是否有像素，并生成预览；它不能修复布局错误、角色漂移、缺动作或画出来的棋盘格背景。发现这些问题应修订素材或提示词，保留失败证据，不把归一化当成动作验收。
