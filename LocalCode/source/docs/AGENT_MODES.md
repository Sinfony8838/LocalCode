# LocalCode 0.2：审批、附件、计划与目标

## 使用

输入框左下的加号菜单添加图片、UTF-8 文本或只读文件夹上下文。图片可粘贴、拖入、选择，发送前可删除和放大，发送后仍保存在聊天中。每条消息最多 10 个附件、总计 50 MiB；单图 10 MiB，单文本 2 MiB。文件夹沿用有界分页和目录忽略规则，不自动整目录发送给模型。

外部模型在“模型设置”中勾选图片输入能力。本地 Ollama 通过 `/api/show` 能力响应判断，不会为了探测能力调用生成接口。含图片的消息或历史不能静默切换到不支持图片的模型。实际图片理解效果由所选模型决定。

审批选择器提供：

- **请求批准**：项目内常规文件工具直接运行，终端和未授权的外部路径请求批准。
- **帮我批准**：执行已明确授权的规则，其他操作询问。无 Windows 沙箱时，即使 PowerShell 能完整解析，也不代表它可安全自动运行；未匹配命令仍询问。
- **完全访问权限**：跳过常规询问，以当前 Windows 用户权限运行，不提供管理员提权。

审批卡可允许本次、允许本会话相同范围或拒绝。命令授权绑定完整命令和工作目录，不自动生成宽泛前缀规则。授权不跨会话、不在重启后保留。文件工具继续保护应用数据、真实路径和写入冲突；这些控制不是 OS 沙箱，已经批准的 PowerShell 仍具有当前用户的系统访问能力。

## 计划模式

启用计划标签后，只提供受控读取、浏览、搜索、问答和计划工具。Agent 可以用问题卡澄清范围，然后给出计划卡。点击“开始实施”才进入执行；“继续修改”保持计划模式。“完全访问权限”不能让计划模式写文件或运行任意终端。

计划、回答等待和附件均绑定原会话。切换聊天不改变正在执行任务的权限，运行中模式与审批选择冻结。

## 目标模式

目标模式仅支持外部模型；本地 Ollama 在 UI 和主进程均禁止创建、恢复目标。本地普通任务仍保留每轮 12 次工具调用上限，所有外部模型任务取消这一固定上限。

目标默认累计有效工作 2 小时，可在创建或目标卡中调整为 0.25–24 小时。不设总轮数或额外 token 预算。模型工作和工具执行计时；排队、退避、审批等待、问题等待、计划讨论和暂停不计。目标只在本轮清理、文件统计和保存完成后继续，用户输入优先。

支持暂停、恢复、清除和调整预算。停止任务同时暂停目标；重启应用保持暂停。到达预算会取消正在执行的推理和命令，保留预算用尽状态，不当作完成，也不额外调用模型总结。完成通过结构化状态工具提交验证依据；普通最终回复不会自动标记目标完成。自动续跑轮没有工作工具调用时停止继续并等待用户处理。

文件夹附件为只读上下文，不扩大文件工具的写入范围。外部文件经批准后可被文件工具修改并记录、撤销；外部文件预览仅展示源码，避免授权旁边未选择的 HTML 资源。

## 实现与验证边界

开源来源、固定提交、许可证和适配差异见 `../THIRD_PARTY_NOTICES.md`，原始参考保存在 `../third_party/`。规则/解析、目标状态和供应商协议分别采用 OpenCode、Codex 与 pi SDK 的相应机制。

验收脚本 `scripts/acceptance-agent-modes.mjs` 使用独立数据目录、本机 HTTP 模拟协议及真实 pi SDK/Electron，不读取生产密钥、不调用付费模型。图片协议验收证明请求携带图片，不等同于真实模型视觉能力验收。两小时截止使用隔离持久计数接近上限后实际运行来验证取消，不需要消耗两小时推理。

新版本独立存放在 app/releases，验收通过后才切换 app/current.txt；旧版保留，可回退启动指针。不会覆盖旧发行目录、删除历史会话或自动重放命令。
